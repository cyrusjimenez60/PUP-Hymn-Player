# PUP Hymn Player

This mini-project applies basic HTML, CSS, and JavaScript fundamentals in creating an interactive music player, specifically for the Polytechnic University of the Philippines (PUP) Hymn.

## Live Demo
Click the link to visit the live site and listen to the PUP Hymn with synced lyrics:
[pup-hymn-player-nu.vercel.app](https://pup-hymn-player-nu.vercel.app/)

## Features
- Embedded music player for the PUP Hymn
- Time-synced lyrics display, inspired by Apple Music's translucent UI
